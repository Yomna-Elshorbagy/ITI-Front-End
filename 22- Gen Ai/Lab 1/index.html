📚 About QuickSort Algorithm

How It Works:

  • Selects a pivot element
  • Partitions array around pivot
  • Recursively sorts sub-arrays
  • Combines sorted results

Complexity Analysis:

  • Best: O(n log n)
  • Average: O(n log n)
  • Worst: O(n²)
  • Space: O(log n)

Advantages:

  • Very fast average case
  • Cache-friendly
  • In-place sorting
  • Widely used

Disadvantages:

  • Unstable sort
  • Poor worst-case
  • Not adaptive
  • Complex code
